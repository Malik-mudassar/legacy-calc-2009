Detailed Description

Represents a single fixed-rate, amortizing loan.

The class holds the principal amount, annual interest rate, and term in years, and provides methods to calculate key financial figures like monthly payment.

◆ monthlyPayment()

long double Loan::monthlyPayment ( ) const

Calculates the Equal Monthly Installment (EMI).

Calculates the Equal Monthly Installment (EMI) based on the standard amortization formula.

The calculation uses the standard amortization formula and handles the edge case of extremely long tenures to prevent floating-point overflow. The result is rounded to two decimal places.

Returns
The monthly payment amount (EMI).

Formula: EMI = P * r * (1+r)^n / ((1+r)^n - 1) Includes a special case for 0% interest and a check for floating-point overflow in the exponentiation term (pow_term).

Returns
The monthly payment amount (EMI), rounded to two decimal places.

This version serves as the canonical implementation. It handles the 0% rate case but assumes the inputs are reasonable and does not include the explicit LargeTenure overflow check, relying on standard library behavior.

Returns
The monthly payment amount (EMI), rounded to two decimal places.
